# Examples

## Admit exploration from a structured Twin intent.

Bind exact subject/world heads and authority, execute once by idempotency identity, and return event plus receipt.

## Converge two partitioned worlds.

Replay causal additions, deduplicate event IDs, preserve forks, and never replace history with a latest snapshot.

## Create an invited portal.

Place only closed-portal collision data in `publicPayload`. Encrypt exact geometry, invite proof, identities, and metadata through `client.world.planPrivateCommand`. Persist the exact plan, validate, execute, then use execution lookup before retry. Revocation blocks future envelope delivery without rewriting the public creation event.
