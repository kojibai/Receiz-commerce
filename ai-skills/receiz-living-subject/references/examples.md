# Examples

## Move the same creature into another Receiz application.

Verify the exact artifact, preserve identity/genesis/history/unknown namespaces, append the application namespace, and retain conflicts as forks.

## Transfer the creature to a new owner.

Issue an exact-head one-time instrument, accept it atomically, preserve the subject, revoke former-owner authority, and return a sealed transfer receipt.

## Capture and admit a creature.

Verify the enclosing creature-card proof object, derive the semantic idempotency key, call `client.subjects.admit` with `expectedAbsent: true`, and store the edge bundle. A timeout repeats the exact proof bytes/key; a conflict returns `writes: 0`. The database only syncs and recovers the object-carried truth.
