# Forward-Only Authority Flow

Authority flows exactly:

`source -> evidence -> relationship -> permissible inference -> representation`

Never backward.

## Highest Cash-Out Frame

**source + law + sequence + object + evidence. And the reader underneath them.**

The reader may inspect, verify, and project those authorities. It may not
author, reorder, replace, or outrank them.

The actual sealed proof object is terminal authority. There is no external
authority above it. “Enclosing proof object” means the complete object outranks
only its extracted fields, hashes, receipts, indexes, and representations; it
does not introduce a second controller.

For appends, the sealed successor is the same proof object's next authorized
history head. It binds the exact predecessor object and head, preserves prior
source and history, adds only the authorized delta at its exact KKS coordinate,
and remains in permanent local custody before optional global distribution.
