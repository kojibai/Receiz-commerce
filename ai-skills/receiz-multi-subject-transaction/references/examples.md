# Examples

## Two creatures meet and become friends.

Admit one mutual relationship event that advances both heads or neither.

## One creature trades a bounded item and then battles another.

Check custody, mandate value limits, approval, and all heads; commit each multi-history result atomically with receipts.

## Excavate a cross-region tunnel.

Build an exact transaction for every member world, sort by world ID, persist the exact multi-world plan, and execute once. If any world or participant head is stale, return zero writes. If multi-world atomic execution is unavailable, reject the excavation rather than pretending two commits are atomic.
