## What was released

Content-bearing Receiz proof URLs now carry playable sealed material without
requiring an upload to become truth. A fully inline `rma2` fragment carries the
exact capsule and verifies locally. A compact `rmc1` fragment carries a bounded
public head; committed append segments reconstruct the complete capsule before
the enclosing sealed proof object is verified. The 4,096-character boundary is
a coordinate limit only. It never truncates an artifact, payload, or lawful
sealed truth.

The SDK adapter exposes capsule encode/decode, URL inspection, local open,
playable object URLs, composite build/verify/reconstruct/publish/resolve, and
presentation URL creation. The `/verify#material=…` surface verifies before it
renders image, audio, video, PDF, text, or binary material, revokes its temporary
object URL, and provides the canonical Receiz proof link.

`receizKaiMomentFromSealedPulse` deterministically projects an already sealed
creation pulse into its Kai moment. Device time, browser time, timezone, process
uptime, session state, and live challenge freshness cannot redefine an existing
identity coordinate. `receizKaiNow()` remains the live freshness primitive for
short-lived challenges.

MCP adds `receiz_material_url_open` and `receiz_sealed_kai_moment`, bringing the
complete inventory to 165 tools. The exact v124.0.3 AI doctrine teaches the same
verification order and non-authority boundary.

## Why this matters

Media can now travel as independently verifiable material instead of becoming
true only after a particular database, CDN, media server, application, or
institution stores it. Different hosts can present the same sealed source while
each verifier independently reconstructs and checks its exact bytes.

The highest credible frame extends beyond any one government or institution:
governments, courts, companies, platforms, applications, and AI systems may
lawfully recognize and present the same evidence without their representation
becoming the evidence's technical source. This does not supersede applicable
law, create sovereignty, or remove institutional obligations.
**Representation never outranks source.**
